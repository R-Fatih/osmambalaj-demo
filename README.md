# OSM Ambalaj — Tasarım Önizlemesi

Yeni osmambalaj.com.tr sitesinin statik tasarım önizlemesi (Türkçe + İngilizce).

**Canlı önizleme:** https://r-fatih.github.io/osmambalaj-demo/ — English: https://r-fatih.github.io/osmambalaj-demo/en/

Bu depo yalnızca otomatik üretilmiş HTML/CSS içerir. Formlar, ürün yönetimi ve yönetim paneli
asıl uygulamada (ASP.NET Core) çalışır; bu önizlemede form gönderimi kapalıdır.
Sayfalar arama motorlarına kapalıdır (`noindex`).
